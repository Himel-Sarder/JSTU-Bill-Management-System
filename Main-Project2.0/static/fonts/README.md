# Bengali Fonts for PDF Generation

To enable proper Bengali font support in PDF generation, please download a Bengali TrueType font (TTF) file.

## Recommended Fonts:

1. **Kalpurush** - Popular Bengali font
2. **SolaimanLipi** - Standard Bengali font
3. **Nikosh** - Government approved Bengali font

## Steps:

1. Download a Bengali TTF font file (e.g., Kalpurush.ttf)
2. Place it in this `static/fonts/` directory
3. The system will automatically use it for PDF generation
